# V3 kavramsal medya

Bu klasördeki görseller ve sessiz video döngüleri ARF ana sayfasının sinematik
anlatımı için üretilmiş kavramsal varlıklardır.

- `hero-luminous-energy.*`: temel enerji / bilgi katmanı
- `energy-management-system.*`: enerji yönetimi ve korunumu
- `energy-harvesting-field.*`: enerji üretimi ve hasadı

Varlıklar gerçek ürün, laboratuvar, patent, prototip veya müşteri çalışmasını
temsil etmez. Kullanıcı arayüzünde bu ayrım “Kavramsal görselleştirme” etiketiyle
açıkça belirtilir.
